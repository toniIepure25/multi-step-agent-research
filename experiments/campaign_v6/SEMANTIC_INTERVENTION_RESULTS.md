# V6 Semantic Intervention Results

## Status: NOT YET EXECUTED

Infrastructure implemented in `run_v6.py` (run_semantic_intervention function).

## Design

Three conditions on each task:
1. **Real:** Task-specific hypothesis generated by LLM
2. **Shuffled:** Hypothesis from a different task (matched length/style)
3. **Neutral:** Generic non-task-specific hypothesis

All three conditions use identical downstream operations:
artifact → targeted retrieval → reasoning → final decision

Same total LLM calls, same retrieval budget.

## Implementation

The `artifact_override` parameter in `run_closed_loop_sequence()` allows
replacing the hypothesis artifact at a specific operation index.

Shuffled artifacts are drawn from other worlds in the same batch,
ensuring matched format but different semantic content.

## Expected Execution

Pending decision on whether to execute given that:
1. Factorial complementarity is zero
2. The value is entirely from hypothesis generation's main effect
3. Shuffled hypothesis might still bind to a latent hypothesis (just the wrong one)

Semantic intervention remains the strongest possible test of H-REE-20.
If real > shuffled even when factorial interaction is zero, it would
indicate that the content of hypothesis generation matters for quality,
even though additional operations after it don't add super-additive value.
