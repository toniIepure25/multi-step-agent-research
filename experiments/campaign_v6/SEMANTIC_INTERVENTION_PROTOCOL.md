# V6 Semantic Intervention Protocol

## Central Question

Does the SEMANTIC CONTENT of a hypothesis artifact causally improve
downstream information acquisition and task performance?

Or does hypothesis generation help merely because another LLM call occurs?

## Conditions

### REAL
Generate a genuine task-specific hypothesis using the primary model.
The hypothesis references task-specific entities, causal relationships,
and evidence predictions.

### SHUFFLED
Inject a hypothesis generated by the SAME model for a DIFFERENT task.
Matched approximately by length and format. No shared gold information.
Pairing determined deterministically before downstream evaluation.

### NEUTRAL
LLM call with matched compute but no hypothesis semantics.
Instruction: restate the research question and relevant entities without
proposing an explanation, answer, or reasoning conclusion.

### DIRECT_QUERY (baseline)
No hypothesis generation. Query generated directly from the task.
One fewer LLM call. Controls for whether ANY extra processing helps.

### GENERIC_EXPANSION (important control)
LLM call to expand the query into related terms/concepts.
No explicit hypothesis. Controls for "hypothesis is just query expansion."

## Compute Matching

All conditions (except DIRECT_QUERY) use:
- Same number of LLM calls
- Same maximum token budget per call
- Same retrieval budget (top-k evidence)
- Same downstream pipeline (query → retrieve → reason → answer)
- Same model, temperature, max_tokens

DIRECT_QUERY uses one fewer call. This is intentional — it tests
whether the EXTRA CALL itself has value.

## Artifact Length Matching

SHUFFLED artifacts are paired by token-length bucket (±20% tolerance).
If a shuffled artifact is >20% longer/shorter than the real artifact,
reassign to a better-matched task.

## Manipulation Check

Before interpreting results, verify:
1. REAL artifacts have higher task relevance than SHUFFLED
2. All artifact conditions have similar length distributions
3. NEUTRAL artifacts do not accidentally contain hypotheses

## SESOI

For gold evidence recall: 0.05 (5 percentage points)
For final task quality: 0.03 (3 percentage points on 0-1 scale)

## Statistical Test

Paired bootstrap CI (task-level resampling, 10000 iterations).
Primary: REAL vs SHUFFLED.
Secondary: REAL vs NEUTRAL, REAL vs GENERIC_EXPANSION.
